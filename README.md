# 🧠 Nexon AI — Phoebe

One of my current long-term projects is **Nexon AI**, a Windows desktop AI assistant with a character-driven interface called **Phoebe**.

### Current capabilities / experiments

* 🗣️ Voice input and speech recognition
* 🌍 Multilingual transcription
* 🇬🇧 English + Kannada + Kanglish support
* 🎙️ ElevenLabs voice synthesis
* 🧠 Local LLM experimentation with Ollama
* 👁️ Computer vision and camera-based features
* 💻 Code understanding and explanation
* 📂 File searching and analysis
* 🖥️ Desktop automation
* 🔒 PC control and system actions
* 📄 PDF/document understanding
* 🎨 Electron-based desktop interface

The project is designed around one principle:

> **An AI assistant should help automate the computer without taking control away from the user.**
